ATS helps recruiters by filtering out most applicants and leaving only those with matching keywords - but there's still a large pile of resumes left for recruiters to manually go through.

What if we have some tools to help recruiters look through those resumes?

Introducing 2 Post-ATS Resume Screening systems:

1. Job-Resume Similarity Scan
Function: Scores each resume based on how similar they are to the job description
Use-case: Trim down the number of resumes to look through (e.g. top 30%)
Methodology: Vectorization and cosine similarity

2. Unique values of each Resume
Function: Highlights unique keywords in each resume
Use-case: Quickly identify what sets each candidate apart from the rest
Methodology: TF-IDF (Term Frequency - Inverse Document Frequency)

This is a proof of concept. If there is any interest in turning this into a proper system, please contact me.
